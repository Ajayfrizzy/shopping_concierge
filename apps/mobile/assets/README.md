# Shopping Concierge icons

Temporary, replaceable branding: an ivory shopping bag and gold detail on pine green. The same artwork supplies the opaque 1024px Expo icon, transparent adaptive foreground, and Android monochrome mask. Foreground artwork stays within the adaptive safe area.

`icon.svg` is the editable vector reference. Run `python scripts/generate-icons.py` with Pillow installed in a separate tooling environment to reproduce the PNG exports; Pillow is not an application dependency. Update these assets and rebuild the native app when final branding is available.
