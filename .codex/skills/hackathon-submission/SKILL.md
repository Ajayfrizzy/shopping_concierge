# Skill: Hackathon Submission

Use during polish/submission work.

## Story
Present the product as a stateful purchasing-decision agent using YouCam as visual evidence—not as a generic chat stylist or VTO wrapper.

## Demo must show
- natural-language goal
- persistent constraints
- grounded catalog recommendations
- rejection reason changing behavior
- real YouCam VTO
- selected product anchoring a cross-category search
- criteria-grounded comparison
- transparent state change / no-match honesty

## Claims discipline
Do not claim novelty for chat, VTO, multi-category support, comparison, or recommendation individually. Emphasize the integrated decision state, feedback memory, cross-product dependencies, constraint preservation, and selective visual verification.

## Submission artifacts
Maintain:
- README
- judge guide
- 1–3 minute demo script
- API/use table
- architecture summary
- setup/access instructions
