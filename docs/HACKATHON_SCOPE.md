# Hackathon Scope

## Submission story
Demonstrate a stateful purchasing-decision agent rather than a generic stylist/VTO wrapper.

## Must visibly demonstrate
- natural-language goal
- persistent constraints
- real catalog results
- rejection reason influencing next result
- VTO on a real supported category
- cross-category dependency
- comparison grounded in user criteria
- transparent state changes

## Avoid claims
Do not claim that chat+VTO, multi-category VTO, recommendation, or comparison individually are novel. Position novelty in the integrated stateful decision workflow.
