# Evidence index

Evidence paths are stable because reports, scripts and adjacent media/JSON depend on them. These are dated observations, not current provider balances, runtime status or final submission footage. [Final acceptance](../archive/acceptance/FINAL_PRODUCTION_ACCEPTANCE.md) is the historical code-6 baseline; [final demo plan](../archive/demo/FINAL_DEMO_PLAN.md) is an executed historical plan. Use [Android v11 release](../ANDROID_RELEASE.md), [implementation coverage](../IMPLEMENTATION_COVERAGE.md) and the [published demo](https://youtube.com/shorts/8SNE4YJEOBI?feature=share) for current navigation.

## Reading the evidence

- [Android v7 upload recovery](upload-recovery-v7/acceptance.json) — exact installed APK, native recovery/restoration and unchanged paid-operation counts; no render or video.

- [Native calibration measurements](demo-calibration/native-run.json) — sanitized October 19 mock timings and bounds; [interpretation and limitations](../archive/demo/NATIVE_DEMO_CALIBRATION.md). No live render or final video.

- [Image provenance](IMAGE_PROVENANCE.md) records publication review and approved synthetic portraits; code licensing alone does not establish image permissions.
- [Historical all-category live YouCam evidence](youcam-live) contains genuine provider validation; optional live analysis remains unvalidated. Signed render URLs expire.
- [Production acceptance evidence](final-acceptance) supports the final audit where available; the audit describes its exact scope.
- [M9 rehearsal](m9/README.md) uses mock providers plus a labeled historical live capture. It is not the final demo video.
- Offline/mock native VTO tests do not establish genuine provider image quality. Budget/account-credit JSON and Markdown refer only to their observation dates.
