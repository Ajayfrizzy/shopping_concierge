# Three-minute demonstration

Prepare the local demo using [setup](../../DEMO_SETUP.md). Start on an empty guest session with no keyboard showing. Keep the [validated live evidence](../../JUDGE_GUIDE.md#validated-youcam-evidence) open in a separate viewer; this segment is explicitly a prior live capture, not a mock render. A continuous Samsung UI rehearsal completed in **106.01 seconds (1m 46s)** on 2026-10-07: [recording](../../evidence/m9/timed-demo.mp4), [measured checkpoints](../../evidence/m9/timed-demo.json). It uses ADB-driven input on the real device and has no narration. The schedule below allows additional narration time.

| Time      | Action                                                                                                                                      | What to show / say                                                                                                                                                                                                                                                                              |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 0:00–0:25 | Tap **Use this example**, then **Send to concierge**.                                                                                       | “Silver earrings for a wedding under $120, elegant but not too loud.” Show exact catalog cards and **What changed**. Catalog, prices and stock are labeled synthetic.                                                                                                                           |
| 0:25–0:45 | Send `Reject E05 as too flashy`, then `Show me cheaper ones`.                                                                               | E05 is removed and rejection stores `too_flashy`; related eligible candidates can receive feedback penalties. Cheaper changes price preference, preserving silver, wedding and the $120 cap. E05 is an actual silver fixture; **Tell me about E05** can show its facts in a longer walkthrough. |
| 0:45–1:05 | Send `Try on E18`; tap **Open try-on**. Briefly show the on-demand portrait prompt, then switch to the previously captured earrings output. | “Try-on is optional evidence. This is the validated live YouCam capture; the current demo is mocked and generates no rendering.” Mention necklace/ring/watch also passed; no paid request is needed. Return to shopping.                                                                        |
| 1:05–1:30 | Send `Select E18`, then `Now find a necklace that works with this under $100`.                                                              | Show **Coordinating with selected E18** and exact necklaces. Selection creates an explicit dependency; only necklace budget becomes $100. The stored rejection reason remains available to rank relevant eligible candidates along that dependency.                                             |
| 1:30–1:50 | Send `Compare N01 and N02`.                                                                                                                 | Show actual prices/materials, current criteria, eligibility and grounded evidence. No invented beauty judgment or recommendation outside hard constraints.                                                                                                                                      |
| 1:50–2:15 | Open **Session summary**, return, then send `Back to earrings`.                                                                             | Show selected E18 and rejection history. Earrings still have their $120 cap; necklace context is preserved independently.                                                                                                                                                                       |
| 2:15–2:45 | Send `Platinum earrings under $1`; tap **Set budget to USD 35 and try silver instead**, then **Cancel**.                                    | Zero exact matches; proposed relaxations are separate. Nothing silently changes on cancel. Plain “yes” cannot approve a relaxation.                                                                                                                                                             |
| 2:45–3:00 | End on the no-match state or summary.                                                                                                       | “The contribution is integrated decision state, feedback memory, selected-product relationships and selective visual verification.”                                                                                                                                                             |

If scrolling/typing exceeds three minutes, record with deliberate cuts between the above actions and disclose the edit; do not remove mock/live labels or present old evidence as a new render. The recorded continuous run establishes the physical timing; final narrated video review remains a publication task. Use only supported utterances in mock mode; arbitrary language may produce honest clarification.
