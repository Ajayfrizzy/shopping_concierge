## Claims corrected or not substantiated

The old API route sketch advertised reset/search/action/events routes absent from the router. The current contract documents the implemented message/action transport instead. Early data-model tables were conceptual; migrations, not that sketch, define deployed SQL. Old code-6/836-test notices and pending recording instructions are historical. “Real catalog” means validated sample records, not retail inventory. Selection does not imply universal/permanent taste learning. Optional live analysis, camera capture, automatic signed-result renewal, server-attested consent and distributed exactly-once provider execution are not supported claims.

No current signed URL availability, exact deployed Git revision, fresh accounting balance or independent organizer-rule acceptance was established by this documentation audit. The October 24 GitHub advisory report (two high, three moderate) remains unresolved; older npm reports describe different dependency snapshots.
