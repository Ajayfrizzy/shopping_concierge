# Documentation

Shopping Concierge is a hackathon beta using **72 synthetic products**, sample prices and availability. The published standalone Android app is version **0.1.0 / code 11**, ARM64 / Android 7+, and requires internet and the live backend. Android v11 acceptance recorded **983 integration-enabled tests passed**. The official narrated demo is published; these dated checks are not continuous certification.
