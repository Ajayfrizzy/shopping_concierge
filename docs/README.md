# Documentation

Shopping Concierge is a hackathon beta using **72 synthetic products**, sample prices and availability. The published standalone Android app is version **0.1.0 / code 6**, ARM64 / Android 7+, and requires internet and the live backend. Final acceptance recorded **836 passed tests, zero failed/skipped** on October 18–19, 2026. This is a dated baseline, not continuous certification.
