# Documentation

Shopping Concierge Android **0.1.0 / code 11** is the current public beta. The catalog contains 72 synthetic products, sample prices/stock and original illustrations; there is no live merchant inventory or checkout. The final 150-second narrated demonstration is published, with genuine E01 YouCam output and disclosed same-session pickups.
