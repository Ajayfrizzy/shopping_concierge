# Future Roadmap

Potential post-hackathon expansion:

- bracelets, bags, hats, shoes, apparel
- real retailer feeds and live inventory
- merchant onboarding and catalog tooling
- checkout/payment handoff and later approved purchasing flows
- order/shipping tracking
- richer user preference learning
- wardrobe/context integration
- voice interface
- merchant analytics/dashboard
- retailer plugins/integrations
- production recommendation evaluation and experimentation

These must not distract from MVP reliability unless explicitly reprioritized.
